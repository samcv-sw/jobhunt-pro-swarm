⚡ بوابة المطورين والشركاء التقنيين

ابنِ تطبيقاتك على محركات الذكاء الاصطناعي لسوق العمل

واجهات برمجة تطبيقات (APIs) فائقة السرعة لفحص السير الذاتية، وتحليل جاهزية الـ ATS، واستخبارات سوق التوظيف الخليجي.

🔑 توليد مفتاح تجريبي مجاني (Sandbox API Key)

احصل على 100 استدعاء API مجاني لاختبار التكامل في بيئة التطوير الخاصة بك.

مفتاح الـ API الخاص بك:
POST /api/public/instant-cv-pulse

فحص السيرة الذاتية ورصد الـ ATS

يحلل نص السيرة الذاتية عبر 4 ركائز ويرجع نسبة التوافق وقائمة الشركات الخليجية المتطابقة.

curl -X POST https://jobhuntpro.io/api/public/instant-cv-pulse \
  -H "Content-Type: application/json" \
  -d '{"cv_text": "Senior Cloud Architect with AWS/GCP experience in Riyadh..."}'
GET /api/market-radar/summary

رادار الوظائف والرواتب الحية

استرجاع مؤشرات الطلب وسرعة التوظيف ومتوسط الرواتب في الرياض ودبي والدوحة.

curl -X GET https://jobhuntpro.io/api/market-radar/summary \
  -H "Authorization: Bearer YOUR_API_KEY"
